# Superpowers skills

These 15 skill directories and their supporting files are copied from
[obra/superpowers](https://github.com/obra/superpowers) at commit
[`2ce8aa15d05bd57213e6f746f953aafb7ded7a8b`](https://github.com/obra/superpowers/commit/2ce8aa15d05bd57213e6f746f953aafb7ded7a8b).

The installation is local to this project. Each skill has its own `SKILL.md`
for discovery. The upstream files are unmodified; the MIT license is preserved
in [LICENSE.superpowers](LICENSE.superpowers).
